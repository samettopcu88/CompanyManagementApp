# 🏢 Company Management Application

Company Management Application is a multi-layered C# application designed to manage various aspects of company operations. It follows a modular architecture, separating concerns across different layers for better maintainability and scalability.

## 🚀 Technologies Used

- C#
- .NET Framework
- Windows Forms
- Entity Framework
- SQL Server

## 🧱 Project Structure

- **CompanyManagementApp.API**: Handles HTTP requests and serves as the entry point of the application.
- **CompanyManagementApp.BAL**: Contains business logic and service implementations.
- **CompanyManagementApp.DAL**: Implements data access using Entity Framework.
- **CompanyManagementApp.Entities**: Contains core entities and interfaces.
- **CompanyManagementApp.UI**: User interface developed using Windows Forms.

## 🎯 Features

- Employee management
- Department management
- Project tracking
- Reporting and analytics
- User authentication and authorization
